# Спецификация: приведение Agents.md к стеку mathsteps

## 1. Цель

- Исправить кодировку `Agents.md` на UTF-8, чтобы текст читался корректно.

## 2. Текущее состояние (AS-IS)
- `Agents.md` содержит правила, ориентированные на UI/E2E (Playwright, Vite, React/Vue/Angular, Vitest) и команды, которых нет в проекте.
- Файл отображается в mojibake (битая кодировка).
- В проекте используются `mocha` и `eslint`, команды `npm test`, `npm run lint`, `npm run setup-hooks` (см. `package.json` и `CONTRIBUTING.md`).
